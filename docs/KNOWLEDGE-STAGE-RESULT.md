# 个人笔记检索阶段结果

日期：2026-10-13

本阶段在不增加向量检索或常驻服务的前提下，完成了扫描一致性与扩词触发的保守改进。

笔记扫描状态通过 `snapshot().noteScanStatus` 暴露，包含 `idle`、`complete` 或 `incomplete`、检查文件数、错误计数及最多 20 条错误。目录不可达、权限拒绝、文件读取失败、预算中止或索引异常时会记录不完整状态，并跳过 `retain`，因此未检查文件的旧索引仍保留。保留只用于后续恢复：搜索结果只允许本轮已确认可读且有效的段落；拒绝读取的旧内容不会披露。部分扫描中，已更新文件只暴露本轮重建出的段落，旧尾段不会泄露。完整扫描才清除过期及删除条目。切换或断开 Vault 会重置状态。

模型扩词仅在没有精确标题/heading 命中、也没有足够长的完整原文短语命中时执行。多条弱关键词命中仍会扩词；零命中同样沿用现有规划、缓存和失败回退逻辑。完整短语门槛为规范化后至少 5 个字符。该触发策略是可测的保守启发式，尚无真实评测证明其最优。

新增定向测试覆盖精确标题命中跳过扩词、三条弱命中仍调用扩词、权限拒绝时不披露旧命中且确认底层索引仍保留、部分扫描中文件缩短时屏蔽旧尾段，以及 Vault 不可达后恢复完整扫描清除已删除条目。索引初始化也已移入异常处理范围，以便初始化失败时记录 `incomplete`。

主代理已统一串行运行检索/索引/学习/Vault与审查五文件25项定向测试；旧断言更新并保留规划失败回退覆盖后，检索文件7项复验通过，最终相关用例均通过。该检索新策略尚未真实模型复验，未构建或全量测试。目录不可达测试使用不存在的 Vault 路径模拟；系统级权限变化仍需在目标环境验证。
