<h1 align="center">Reed 苇</h1>
<p align="center"><b>把资料放在身边，把想法变成行动。</b><br>一个常驻 Windows 桌面的个人 Agent，陪你读、帮你做、让学过的内容留下来。</p>

<p align="center"><a href="../../releases/latest">下载 Reed</a> · <a href="#快速开始">快速开始</a> · <a href="#从一件具体的事开始">使用示例</a></p>

你正在读一份教材，遇到一个解释不清的概念。把资料放在 Reed 左侧，在右侧直接问；选一段原文带进对话，继续推导、做题，再把这一轮问答放进画布。临时冒出的问题可以交给侧边聊天，主线仍然留在眼前。

Reed 也能处理日常工作：读取文件、整理材料、检索笔记、浏览网页，在你允许的范围内完成修改。你选择模型、项目和权限，Reed 把资料、工具与对话接在一起。

## 用它做什么

| 场景 | Reed 能帮你 |
| --- | --- |
| 阅读教材与课件 | 在对话旁打开 PDF、PPTX，按页阅读，结合当前资料提问 |
| 读网页与 HTML | 内置浏览器支持导航、书签、阅读位置恢复、选中引用与整页读取 |
| 理解难点 | 在回答中呈现公式、推导、对照与互动练习；用临时聊天展开支线问题 |
| 复习与自测 | 管理科目与题库，生成模拟题、作答、提交和查看反馈 |
| 梳理知识 | 用对话画布回看问题与关联，从节点返回原文或继续追问 |
| 使用已有笔记 | 连接 Obsidian Markdown 笔记库，检索原文并查看引用来源 |
| 完成项目任务 | 选择工作文件夹，允许 Agent 使用文件、搜索、浏览器及按需连接的 MCP 工具 |
| 延续个人习惯 | 按需启用学习画像、知识记忆与工作经验，查看和管理保存内容 |

## 快速开始

### 1. 下载并打开

在[发布页面](../../releases/latest)选择适合你的版本：

- **安装版**：运行 `Reed-0.4.0-setup.exe`，按向导安装。
- **便携版**：完整解压 `Reed-0.4.0-portable.zip`，打开 `Reed.exe`。请保留随包的 `agent` 和 `runtime` 文件夹。

支持 Windows 10 / 11，需要 Microsoft Edge WebView2 运行时。安装版可在缺少运行时时引导下载。自行构建的未签名安装包可能显示 Windows 发布者提示，请先核对下载来源。

### 2. 连接你的模型

打开 **设置 → 模型**，添加提供商，填写服务地址与 API Key，获取或手动添加模型并启用。回到主窗口，在输入栏选择模型。

Reed 支持 OpenAI Chat Completions 与 Anthropic Messages 兼容接口，可连接兼容的云服务或本地模型服务。服务地址、模型名称、思考档位和图片能力以提供商实际支持为准。

### 3. 开始第一段对话

先输入一个具体任务，例如：

> 请帮我理解梯度下降。先讲一个直观例子，再用一道小题检查我是否掌握。

需要处理项目文件时，先用输入栏的文件夹按钮选择工作区，再说明希望得到的结果。Agent 请求修改时，检查权限提示后批准。

### 4. 把资料放到对话旁

点击页头的 **学习资料**，新建或选择科目，导入 PDF / PPTX。打开一页后直接提问；需要精确引用时选中文字，再将原文带入对话。

点击 **内置浏览器**，输入网址、搜索内容，或打开 HTML。用收藏按钮把页面放到横向书签栏，左右滚动即可寻找；「书签」入口可集中管理。

### 5. 按自己的习惯调整

- **设置 → 通用**：选择深浅主题、调节字体大小、配置呼出快捷键和开机启动。
- **设置 → 角色**：选择角色说明与技能，按需开启学习目标、学习画像和对话画布。
- **设置 → 笔记库**：连接已有 Obsidian 库，按需生成导航总览。
- **设置 → 权限与范围**：查看工作区、只读目录与审批方式。

## 从一件具体的事开始

**读懂一章教材**

1. 导入教材，打开要学的页面。
2. 提问：「结合当前页，解释这个定义的前提，并给一个反例。」
3. 对某一步仍有疑问时，打开侧边聊天追问。
4. 主线学完后，要求出几道检查理解的小题，或在学习资料的练习区生成模拟题。

**整理一个项目**

1. 选择工作文件夹。
2. 提问：「先阅读这些材料，列出需要交付的内容和缺失信息。」
3. 确认方向，再让 Agent 创建或修改文件。
4. 在工具记录中查看操作过程，回到文件核对成果。

**把零散问答串起来**

1. 在角色设置中开启对话画布。
2. 展开画布，查看问题卡片与关联。
3. 调整节点布局、查看原文，或沿节点继续追问。画布按会话保存。

## 让桌面更顺手

Reed 可通过全局快捷键唤出，也可以常驻托盘、置顶窗口。资料、网页和画布与主对话共享分栏体验：拖动分界线调整空间，方向键微调，双击恢复默认。

窄窗中，临时侧边聊天离开焦点后会变淡，让主对话仍然可见；鼠标移入或重新聚焦时恢复。界面与正文沿用主对话的字体体系，可在设置中调节字号。网页、PDF 和课件原页保留自身排版。

## 数据、模型与权限

- 会话、设置与记忆保存在本机；导入资料会保留本地副本，原文件不会被替换。
- 使用云端模型时，问题、选中的引用、附件及工具读取的相关内容可能发送到你配置的服务；本地存储不等于所有处理都离线。
- API Key 使用 Windows 当前用户加密保护，不写入会话正文。
- 文件工具默认限制写入工作区，可在设置中调整权限。权限设置控制 Reed 的文件工具范围。
- 模型费用由所选服务收取。画布整理、题目生成、部分评分与记忆整理也可能产生模型请求。
- 扫描 PDF 可导入对应的 MinerU 解析结果，或自行配置可选的单页识别服务；Reed 不附带 OCR 模型。
- AI 生成的解释、题目和评分需要核对，尤其是重要结论与实际交付内容。

升级前请从托盘退出旧版，避免多个实例争用同一份数据。升级与卸载默认保留用户数据。

## 从源码构建

需要 Node.js 22.19+、Rust stable、Windows C++ 构建工具与 WebView2 运行时。在仓库根目录执行：

```powershell
npm ci
npm run agent:install
npm test
npm run build
npm run build:setup
```

便携版与安装版会包含 Agent 运行所需的 Node.js。应用内更新产物需要维护者配置发布签名；未配置签名时，请从发布页面下载新版本。
