# 间隔复习

1. 读取当前学习画像中的待复习概念、误解和用户指定范围；用 current_time 获取真实时间。没有记录时让用户指定一个主题，不编造过往学习历史。
2. 用 search_notes 找到相关笔记与具体段落。优先选择明确待复习或用户当前想复习的内容；引用返回的文件链接。
3. 先提出一个不泄露答案的回忆问题，等待作答；必要时给提示，再展示笔记里的定义或解析。
4. 根据用户实际作答分类：只有用户先尝试、未获提示且答案正确，才标为 `independent`；提示后答对标为 `prompted`；答错或未能回忆标为 `incorrect`。没有直接作答或证据不清时，不猜测结果。结果仅安排复习日期，不代表掌握程度，不更新掌握百分比。
5. 用户完成复习后，按 record_learning_event 的真实参数保存复习证据。若无法确认结果，可省略 `result`；系统会以 `unknown` 保守记录并安排次日复习。记录失败或记忆关闭时明确说明，不能声称已经保存。
6. 只有保存成功后，才能向用户报告回执中的实际主题和 `nextReview` 日期；不要自行重新计算日期或把建议说成已保存。尊重用户日程和已有复习计划。

当前流程提供复习建议与学习事件记录，并不自动创建提醒或后台任务；只有可用工具实际创建成功后才能声称已安排提醒。Obsidian 原笔记保持只读。
