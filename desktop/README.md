# Reed 苇 · 便携版

运行 `Reed.exe`，保留同目录 `agent/` 和 `runtime/`。在设置中配置并启用模型，在聊天底部选择模型开始对话。

画布入口：编辑角色，开启“学习模式 → 对话画布”。已有角色开关即时保存，聊天区左上展开画布，右上展开学习目标。画布使用当前模型整理，可能产生额外请求。

左下项目按钮可恢复历史项目或选择文件夹；历史项目标题旁的＋可快速新建会话。

更新前通过托盘退出旧版。配置与会话保存在 `%APPDATA%\Reed`，升级和卸载默认保留。启动日志为包内 `startup.log`，Agent日志为应用数据目录中的 `agent.log`；反馈前请删除私人内容与凭据。

完整说明见源码仓库README，第三方许可见随包NOTICE及LICENSE文件。
# 学习资料与可选解析（开发中，待运行验收）

学习资料按科目保存到用户数据目录的 `materials/`，PDF 原文件仅复制，不修改导入来源。阅读与文字层提取使用随包 PDF.js，无需额外常驻服务。PDF 页码指物理页序，区别于书上印刷页码。

扫描 PDF 可导入对应的 MinerU `content_list.json` 或 `middle.json`；保留 `page_idx`，不要只导入合并 Markdown。首次关联需要确认与当前 PDF 对应，页索引越界会拒绝。缓存存于本地，提问只选择相关页面，不整本发送。

“识别本页”为可选服务适配器，不附带 OCR 模型或 Python。用户提供服务地址并确认发送范围；HTTP 只允许本机，远程服务须 HTTPS 并单次明确允许。接口为 POST JSON `{ "image": "PNG base64", "mimeType": "image/png" }`，返回 `{ "text": "识别文字" }`。可用本机代理对接已有识别引擎；内置适配器不隐式调用商业 OCR 或发送整本教材。不设置识别服务仍可阅读 PDF、使用文字层或导入 MinerU 结果。

## 题库与练习卷（开发中，待运行验收）

可以在资料面板导入 JSON 题库、按考点与题型抽卷，也可以要求主对话“根据这章出一套模拟题”或点击“生成新模拟题”。新题生成与非等值简答评分会使用当前模型，可能产生相应调用费用；普通资料自动检索不额外调用规划模型。每题固定 10 分，每卷 1 到 10 题。

试卷先保存快照，再打开作答面板；提交前学生界面与聊天都不接收参考答案或解析。选择题本地判分，简答等值答案可直接判分，其余使用独立教师请求评分。生成题答案和模型评分仍需复核，不能当成权威标准答案。

题库文件是 JSON 数组，一次最多 1000 题，文件最多 2 MB，例如：

```json
[
  {
    "type": "choice",
    "prompt": "1 + 1 等于多少？",
    "options": [{"id": "A", "text": "2"}, {"id": "B", "text": "3"}],
    "answer": "A",
    "explanation": "两个一相加得到二。",
    "topic": "整数加法",
    "difficulty": "easy"
  }
]
```

简答题使用 `"type": "short"`，不填 `options`；`answer` 和 `explanation` 仍必填。可选 `references` 为 `[{"documentId":"当前科目已导入资料的ID","pageIndex":0}]`，页索引从 0 开始。重复题干不会重复导入；题目、答案、试卷与评分保存在用户数据目录中的本地 SQLite，不自动写入长期记忆。
