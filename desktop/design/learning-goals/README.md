# 学习目标交互预览

双击 `preview.html` 用浏览器打开。页面自包含，无需安装依赖、启动 Node.js 或访问网络。

- 右侧抽屉：关闭后显示学习目标把手；宽窗口并排，窄窗口覆盖对话。
- Markdown：正文展示、勾选、编辑、显式保存、取消、离开前未保存提醒；支持 Ctrl/Cmd+S 保存和 Escape 关闭。
- 外观：切换 Reed 浅深主题及宽窄窗口。
- 任务状态：工具执行、长时间等待、失败、完成；按钮仅演示，不发送模型请求。

保存使用独立 localStorage 键 `reed-goals-design-preview-v2`；浏览器拒绝存储时仅在当前页面内保留。此页面不读写应用用户数据，Agent 只读提示为正式设计意图，尚未接入权限逻辑。

内嵌现有 Reed 图标及 marked Markdown 解析器。marked 许可证见同目录 `MARKED-LICENSE`。编辑内容不执行 HTML，图片只显示替代文字。
